# Reference Source Applicability & License Audit

> Audit date: 2026-10-18 (Asia/Dhaka)
> Authoritative implementation: `engralaminn-collab/alaminn.info` on the active Arena branch
> Scope: the 138 deduplicated GitHub repositories supplied by the user, seven supplied GitHub profile links, and the externally hosted product/site labels retained from the request.

## What this audit proves

- All 138 unique repository identifiers were requested through the authenticated GitHub API. Metadata, README content, root trees, and license endpoints were collected for 135; three private/inaccessible repositories returned HTTP 403.
- “IMPLEMENTED” means an applicable pattern has an original implementation in this repository; it never means third-party source was copied or that the referenced application was installed.
- “EXISTING EQUIVALENT” means the current application already has the relevant native capability.
- “LICENSE-RESTRICTED” means reuse is unsafe without a separate license/compatibility review. No code or assets from those sources were copied.
- “REJECTED/INAPPLICABLE” means the source is an unrelated full product, stack, model, operating-system tool, scraper, native application, or infrastructure component whose inclusion would not production-harden this site.
- README and root-tree inspection is not a substitute for a line-by-line security review of an entire third-party codebase. No rejected project was executed.

## Implemented cross-source patterns

1. **Source-backed diagram system:** `/admin/architecture` provides three interactive maps, node evidence, authored downstream tracing, and downloadable SVG/JSON. This is an original implementation informed by the general patterns in `diagram-design` and `archify`.
2. **Marketing kit and content/video pre-production:** `/admin/marketing-studio` creates evidence-bounded campaign briefs, consent/accessibility checks, Markdown exports, and governed AI tasks. It does not pretend to send campaigns or render video.
3. **Education-consultancy journey:** `/higher-study/planner` provides a no-account, browser-private checklist, first-party progress state, user-entered budget scenarios, official immigration links, and JSON export. It states that admissions, funding, deadlines, costs, and visas require current official verification.
4. **CRM/lead intelligence:** `/admin/leads` now ranks record completeness using disclosed first-party fields and displays consent separately. It does not scrape or infer sensitive traits and does not make automated sales decisions.
5. **Communications and AI governance:** existing provider-status, channel-separated inbox, official WhatsApp boundary, durable booking, audit, AI queue, persisted-result approval, and non-publication controls are retained.

## Security and licensing rules applied

- No scraping system, WhatsApp-Web automation, credential relay, “free model API” proxy, video downloader, or autonomous trading agent was imported.
- GPL, AGPL, LGPL, mixed commercial, absent, and unidentified licenses are not assumed compatible. Concept-level observations do not authorize source or asset copying.
- Provider-facing capabilities require official APIs, scoped credentials, encrypted secret storage, callback/webhook validation, idempotency, revocation, consent/opt-out handling, durable delivery evidence, and a tested failure path.
- AI output is a draft from **Al-Amin’s AI Assistant** and cannot be approved before a non-empty persisted result reaches `awaiting-approval`. External communication remains a human action.
- High-resource model/video repositories require separate infrastructure, model-weight licenses, data/likeness consent, provenance, moderation, and cost controls. They are not appropriate runtime dependencies for the current application.
